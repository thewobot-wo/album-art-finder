# Album Art Finder

A Next.js web application for finding and downloading high-resolution album artwork up to 1200x1200 pixels.

## Features

- Search for albums by name and/or artist
- Get high-resolution artwork up to 1200x1200 pixels  
- Download album covers directly
- Powered by Deezer and iTunes APIs
- Responsive design with Tailwind CSS

## Deployment

This app is designed to be deployed on Vercel with zero configuration.

## API

The `/api/album-search` endpoint accepts a `q` parameter and returns album information including high-resolution artwork URLs.
